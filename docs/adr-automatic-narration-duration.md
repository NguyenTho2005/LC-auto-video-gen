# Automatic narration by selected duration

New AI Studio drafts with targetDurationSec synthesize narration before review. Each candidate uses the selected voice, speed and pronunciation (Nam Minh 1.2x by default; ZeroTTS remains available). Actual scene durations include the composition's gap and outro-hold budget. AI rewrites a candidate when fitting would require more than 15% tempo adjustment, or the fitted spoken hook falls outside 2–6 seconds. Narration-only repairs return just scene ids and voiceText, preserving scene designs and the channel outro. Short body scenes request only additional source-backed sentences and append them to existing narration, preventing an AI rewrite from repeatedly shrinking the draft. Feedback gives measured duration and an adjusted per-scene word budget; the full original source remains in the retry prompt. Up to five bounded attempts include schema/editorial fixes. Up to three temporary provider failures (429/502/503/504 or timeout) back off separately without consuming the rewrite budget. No fabricated facts or filler are authorized to meet duration; failure remains visible and does not produce a supposedly verified draft.

Accepted drafts include optional narrationTiming for review and fitDuration=true. Final pipeline measures audio again and fits its timeline to the selected seconds using existing pitch-preserving atempo. Encoded duration is subject to a frame/audio packet rounding error. Uploads keep their original voice, and legacy scripts do not opt in automatically. Review remains available for optional edits; edits change what will be rendered and the final pipeline refits audio. Timing reported before edits describes the generated candidate only.

Network TTS is used in production; unit tests inject measurements and fake LLM responses. No API secrets enter timing reports. Intermediate voice files remain in the draft output folder for diagnostics. Render currently regenerates its local voice cache if a new output directory is selected.
